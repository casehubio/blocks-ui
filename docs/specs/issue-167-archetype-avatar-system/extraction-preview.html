Summary — What Needs Creating

Eyes: Need 5 new variants (narrow, round, almond, deep-set, plus variations of standard). Currently 2 sizes exist.
Noses: Need 5 new variants (prominent, button, narrow, aquiline, broad). Currently 1 pattern exists.
Mouths: Need 7 new variants (line-wide exists as Jester grin; need line-stern, smile, lips-natural, lips-full, smirk, small). Currently 2 patterns exist (neutral + grin).
Ears: Could benefit from 3 variants (pointed, prominent, small) but ears stay coupled to head shape. Lower priority.

Total new feature symbols to create: ~17 (5 eyes + 5 noses + 7 mouths), each at canonical y-positions with per-head offset anchors.
