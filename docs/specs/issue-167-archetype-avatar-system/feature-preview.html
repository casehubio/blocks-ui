Male / Female Lip Strategy

The LucasArts pixel art tradition: lip color is the primary gender signal at low resolution.

  • No lip color (line-neutral, line-stern, line-wide, smile, smirk, small) — reads masculine. The mouth is a dark crease with no fill, varying in width and shape.
  • Lip color (lips-natural, lips-full) — reads feminine. A muted rose/pink (#cc8888 at 35-55% opacity) applied as a fill row at the mouth line. lips-natural is subtle (one row of color), lips-full adds a cupid's bow and fuller lower lip.

Key design choice: lip color is a mouth variant, not a gender toggle. Any archetype can use any mouth. The config table assigns mouths by character personality — Lover/Romantic gets lips-full because they're expressive, not because they're female. This avoids hard-coding gender into the system while still providing the visual vocabulary LucasArts-era games used.

Combination space: 8 mouths × 6 noses × 6 eyes = 288 unique face configurations, plus 11 head shapes × 12 palettes = 132 body configurations. Total: ~38,000 distinct avatars before hair, costume, props, or expressions.
